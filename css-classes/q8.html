Content-Box vs Border-Box

Both boxes below are set to width: 250px and padding: 20px, but they render at different total sizes.

box-sizing: content-box

Width is 250px, but the 20px padding and 4px border are added on top. The box actually renders at 298px wide.

box-sizing: border-box

Width is still 250px, but padding and border are now included inside that 250px, so the box renders exactly 250px wide.

Why it matters

With the default content-box, the width property only sets the size of the content area. Padding and border are added afterward, making the element larger than the width you specified. With border-box, the browser subtracts padding and border from the width you set, so the element's final rendered size always matches the number you typed. Most modern layouts use border-box everywhere to make sizing predictable.
